# Velvet Design System v0.1

## Design character
Velvet should feel refined, fast, private, and calm. It is a professional tool for individuals working in night-work, not a flashy entertainment app.

## Visual principles
- dark-friendly, but support both light and dark modes
- high contrast for late-night use
- avoid excessive gradients, neon, glitter, and nightclub clichés
- use restrained luxury cues rather than decorative excess
- content and actions take priority over decoration
- keep frequent-use screens visually quiet

## Typography
Use a modern system/sans-serif stack with strong Japanese legibility. Prioritize readable labels and short text over editorial styling.

## Spacing
Use a consistent 4/8px-based spacing rhythm. High-frequency controls should have comfortable vertical spacing for thumb operation without creating long screens.

## Shape
Use moderately rounded cards/chips. Avoid extreme pillification of every element; reserve pills for quick values, status, and learned suggestions.

## Motion
- short, functional transitions
- no decorative loading sequences
- immediate feedback for quick actions
- subtle confirmation for auto-save
- respect reduced-motion preferences

## Dark mode
Late-night use is a core scenario. Dark mode must be first-class, not an afterthought. Avoid pure black/pure white extremes where softer surfaces improve legibility.

## Privacy cues
Sensitive contact and personal relationship information should not be visually exposed unnecessarily on list screens. Avoid showing long notes or contact details in app-switcher-visible top-level surfaces.

## AI presentation
Do not establish a separate visual language for AI. AI-assisted outcomes should look like ordinary Velvet functionality unless disclosure is needed for confirmation, point consumption, or error handling.

## Accessibility
- readable Japanese text sizes
- large touch targets
- do not encode state with color alone
- support dynamic text scaling where practical
- primary controls remain reachable when keyboard is open
