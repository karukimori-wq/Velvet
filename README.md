# Velvet

Velvet is a mobile-first sales assistant for individual night-work professionals.

**Core principle:** the user decides what to do; Velvet makes doing and remembering it easier. AI stays in the background and reduces typing, taps, decisions, and repeated work.

## v1.0 surfaces
- People
- Visit
- Capture
- Search
- Schedule

Velvet integrates with Growth Engine, SNS Planner, AI Platform Core, Platform Admin, and professional-platform-contracts.

Product specifications live in `docs/`.
